# Victim Blame in the MeToo Era

This repository corresponds to the paper, "Social movements may trigger backlash by activating threat: Evidence of victim blame in the MeToo Era."

All data and code is provided. 

Data cleaning was conducted in SPSS, analyses were conducted in SAS and R, and plots were created in R.

# Code Files: 

01. VB_Cleaning_Syntax.sps – SPSS syntax used for data cleaning and preparation.

02. VB_Codebook.xlsx – Variable codebook detailing item wording, response options, and coding.

03. VB_Wide_Data.xlsx – Final dataset in wide format.

04. VB_Long_Data.xlsx – Final dataset in long format (for within-subject analyses).

05. VB_Blame_Threat_Analyses_Ideology.sas – Primary analysis code used in SAS (including ANOVAs, regressions, and interactions). 

06. VB_IndirectEffects_Ideology.R – R script used to compute indirect effects in mediation models using ideology via bootstrapping.

07. VB_Blame_Threat_Analyses_SocIdeology.sas – Robustness analysis code used in SAS using social ideology. 

08. VB_IndirectEffects_SocIdeology.R – R script used to compute indirect effects in mediation models using social ideology via bootstrapping.

09. VB_Power.Rmd – R script used to conduct power and sensitivity analyses.

10. VB_Demos_Balance_Checks.Rmd – R script used to conduct balance checks on demographics and the correlation table.

11. VB_Plots.Rmd – R Markdown file used to create plots.
